# Contributing

Contributions should make the project more useful without making the safe path
more expensive or less understandable.

1. Start with an issue that states the operator problem and expected evidence.
2. Preserve the free/local path when adding a hosted connector.
3. Add plain-language tool help, cost class, data boundary, permissions, and a
   working example to the catalog.
4. Default to read-only. Mark writes, destructive behavior, and network access.
5. Add tests and update provenance when adapting outside work.
6. Run `npm run check` before opening a pull request.

By contributing, you agree that your contribution is licensed under the
repository's MIT License.
